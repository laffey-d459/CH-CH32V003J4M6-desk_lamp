项目功能介绍
LED开关频率达到50Khz、色温约4250K、亮度可调，对眼睛友好。
点按触摸按键支持4级调光：百分之零、百分之三十、百分之六十、百分之百。同时长按触摸按键支持在当前亮度基础上进行连续亮度调节，每次长按后松开会切换亮度调节方向。
通过点按将到百分之零会自动切换成增加方向、百分之百会自动切换成衰减方向。长按连续调节亮度都到百分之零后，点按会自动从百分之零开始算；长按连续调节亮度都到百分之百后，点按会自动从百分之百开始算。

注意：遇到触摸无法正常响应，断电后等待一段时间（大约60ms）后重试。



软件部分
利用定时器生成 PWM 信号（PWM1，高电平有效），信号经 1MΩ 电阻接入触摸节点；触摸节点直接连接 ADC 引脚。在定时器更新中断中启动 ADC 转换，采集触摸节点电压。对采集到的原始采样值依次执行中值滤波、一阶IIR滤波，获得平滑纯净的数字电压。将滤波结果与触摸基线做差值运算，以此判断触摸事件。触摸基线采用 PI 控制器实现环境漂移自适应，并引入滞后量，避免基线跟随触摸缓慢下降沿产生误触发。

由于滤波器、控制器存在收敛过程，上电后需等待约 60ms，待滤波器、控制器输出稳定后再开启触摸检测逻辑。
